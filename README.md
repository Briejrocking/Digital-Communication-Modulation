# Digital Communication System Simulation Using Python

## Project Overview
This project demonstrates the simulation and analysis of fundamental digital communication techniques using Python. It covers digital modulation schemes, noise analysis, and bit error rate (BER) performance.

## Objectives
- Understand digital signal generation and modulation.
- Implement ASK, FSK, BPSK, QPSK, and 16-QAM.
- Study the effect of Additive White Gaussian Noise (AWGN).
- Analyse system performance using BER versus SNR.

## Modulation Techniques Implemented
- Amplitude Shift Keying (ASK)
- Frequency Shift Keying (FSK)
- Binary Phase Shift Keying (BPSK)
- Quadrature Phase Shift Keying (QPSK)
- 16-Quadrature Amplitude Modulation (16-QAM)

## Tools and Technologies
- Python
- NumPy
- Matplotlib

## Noise and Performance Analysis
The project implements AWGN to study the effect of noise on transmitted signals.

BER analysis is performed at different SNR levels to evaluate the reliability of the 16-QAM communication system.

## Project Structure
- Python source files: modulation and simulation implementations.
- `outputs/`: generated plots and simulation results.
- `README.md`: project documentation.

## Results
The simulations generate visualisations of:
- Digital modulation waveforms.
- Modulation constellation diagrams.
- Clean and noisy received signals.
- BER versus SNR performance.

## Conclusion
This project provides a practical introduction to digital communication systems through Python-based simulation, demonstrating modulation techniques and the impact of channel noise on communication reliability.
